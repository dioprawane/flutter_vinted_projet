# DIOP Serigne Rawane - Développement Mobile – Application de VINTED

## Objectif
L’objectif de ce projet est de développer une application légère de VINTED qui permet d’acheter des vêtements.

Dans le fonctionnement actuel des entreprises, celles-ci définissent le plus souvent, dans le cadre du développement d’une application, une version MVP (Minimum Viable Product → Produit Minimum Viable). Le MVP est la version d’un produit qui permet d’obtenir un maximum de retours clients avec un minimum d’effort. Ce projet applique cette approche pour définir un MVP.

Par ailleurs, de nombreuses entreprises adoptent les méthodologies agiles et la rédaction de User Stories. Nous allons donc suivre ce formalisme pour exprimer les différents besoins. Chaque User Story composant le MVP sera préfixée de [MVP] dans son titre.

## Présentation du projet
Il s’agit d’un projet Flutter qui démarre avec les fonctionnalités essentielles d’une application de vente de vêtements, inspirée de la plateforme VINTED.

### Fonctionnalités incluses
- Consultation des articles disponibles
- Affichage des détails des vêtements
- Ajout des articles au panier
- Gestion du panier pour les utilisateurs connectés
- Gestion du profil ou compte d'utilisateur
- Prédiction automatique de la catégorie des vêtements lors de l’ajout d’images via un modèle de CNN

### Lancer l'application
Pour exécuter l'application localement, suivez les étapes ci-dessous :

1. **Clonez le dépôt** :
   ```bash
   git clone https://github.com/nom-utilisateur/flutter_vinted_projet.git
   ```
2. **Accédez au répertoire du projet** :
   ```bash
   cd flutter_vinted_projet
   ```
3. **Installez les dépendances** :
   ```bash
   flutter pub get
   ```
4. **Lancez l'application** :
   ```bash
   flutter run
   ```
